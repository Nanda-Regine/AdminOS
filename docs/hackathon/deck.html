Responsible AI

AI drafts. The founder decides.

A · B · C

Three levels of trust

For each decision the owner picks: A acts and reports, B drafts for one-tap approval, C only alerts. Eight decisions are covered today.

1–3

Only courteous reminders can send themselves

Debt follow-ups run in six stages. Stages 4–6 are drafted for the owner and never auto-sent. A content guard blocks threats and legal language.

Zero

Direct database access for AI

The model gets only the text it needs. Inputs are sanitised against prompt injection, and every call is metered.

Capped

A budget the owner can trust

Per-business AI cost caps are enforced on the server, so a runaway prompt cannot become a surprise bill.

Trust · security & POPIA

Your customers’ data stays yours — and apart.

🔒 One business can never see another

  • Row-level security on every table; with the public database key, no business's data can be read (checked 26 Oct 2026)
  • Bank lines are reachable by our server only, never from a browser; payroll and invoices only by that business's own signed-in users
  • Every request is role-checked before any data is read; staff see only their own day
  • A regression check walks 7 industry personas on production: 122 of 122 checks passed
  • Signed webhooks, safe redirects, security patches applied; no raw database errors reach users

⚖️ POPIA, built in

  • Consent checked before any outbound marketing message; customers can opt out
  • Soft-delete and an audit trail on key changes; accounts can be deleted and purged
  • Personal data minimised: AI helpers get no direct database access
  • Privacy policy being updated to list every operator and cross-border transfer (s72) In progress
